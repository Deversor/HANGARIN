# Hangarin - Task & To-Do Manager

This project is a Django-based web application for managing daily tasks, priorities, notes, and subtasks.

## Features
- **Automated Data Generation:** Uses the Faker library to populate the database with realistic tasks and deadline records.
- **Refactored Admin Interface:** Advanced search, filters, and custom column displays for better task management.
- **Relational Database:** Tracks Priorities, Categories, Tasks, SubTasks, and Notes.

## Installation
1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`
4. Run migrations: `python manage.py migrate`
5. Start the server: `python manage.py runserver`
